새 장소 기록

☁️ GitHub Gist 기기 간 동기화

사용 방법 (iPhone ↔ iPad 동기화)
1. GitHub → Settings → Developer settings → Personal access tokens에서 토큰을 발급받습니다.
  · Tokens (classic): gist 항목만 체크 (ghp_로 시작)
  · Fine-grained tokens: Account permissions → Gists → Read and write 선택 (github_pat_로 시작)
2. 첫 번째 기기에서 토큰을 입력하고 [새 Secret Gist 생성]을 누르면 Gist ID가 자동 발급됩니다.
3. 두 번째 기기에서는 동일한 토큰과 발급된 Gist ID를 입력한 뒤 저장하세요. (1MB 초과 방지를 위해 사진은 750KB 단위로 자동 분할 저장됩니다)
